# Portfolio de Constant Anagossi

Site portfolio statique, en français, composé de quatre pages HTML et publié avec GitHub Pages.

## Déploiement

Le workflow GitHub Actions de `.github/workflows/pages.yml` déploie automatiquement le site à chaque mise à jour de la branche `main`.

Dans les paramètres du dépôt GitHub, activez **Pages** avec la source **GitHub Actions**. Consultez ensuite l’onglet **Actions** pour suivre le déploiement et l’adresse du site.

## Pages

- `index.html` — Accueil et projets
- `freshgo.html` — Étude de cas FRESHGO
- `joins.html` — Projet GROUPE JOINS
- `contact.html` — Compétences et contact
